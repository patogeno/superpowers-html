# Second Opinion on a Hard Call

Read this when a call your human partner would normally make has to be
made without them, and it is hard. A call is hard when:

- it can't be undone within a session (a data shape other work will build on, a public interface),
- it changes what users see or do in a way they'd notice, or
- two options both look right and you can't say which is better in a sentence.

Easy calls don't need this: take the option that's easiest to undo, flag it, move on.

## How

1. **Write the question down** in a few lines: what the spec says, what it
   doesn't, and the two (at most three) real options with what each
   commits you to. Leave out which one you lean toward.
2. **Dispatch two fresh agents** in parallel, each with the question, the
   spec path, and the relevant learnings. Brief each to **argue** for a
   different option as strongly as it honestly can, and to say what would
   make it change its mind. On the most capable model you have: this is
   judgment.
3. **Decide.** Weigh both arguments against the spec and your partner's
   feedback so far. When they're close, take the option that's easiest to
   undo.
4. **Record it** in the run log and the report: the question, each option
   in one line with the strongest argument for it, the decision, and
   exactly how to undo it ("say 'reminders every 2 hours' and it's a
   one-task fix").

Two agents, one round. Don't loop the debate; a call you're still unsure
of after this is one to make reversibly and flag clearly.
